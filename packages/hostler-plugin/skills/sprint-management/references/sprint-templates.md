## 1. Sprint Planning

**File**: `templates/sprint-planning.md`

Used during the planning stage before a Sprint begins.

Key sections: Sprint goal, scope, Task plan, dependency analysis, Capacity Analysis, risk analysis, completion-check checklist

---

## 2. Sprint Backlog

**File**: `templates/sprint-backlog.md`

Manages the Task list during the Sprint.

Key sections: status summary, progress, Task details (pending / in progress / done / blocked), priority view, issues and blockers

---

## 3. Sprint Progress

**File**: `templates/sprint-progress.md`

Logs daily progress.

Key sections: progress chart, daily status, burndown chart, key outcomes, risks and issues

---

## 4. Sprint Review

**File**: `templates/sprint-review.md`

Reviews results after the Sprint completes.

Key sections: Sprint summary, completed features, incomplete items, quality metrics, demo feedback, tech debt, deliverables

---

## 5. Sprint Retrospective

**File**: `templates/sprint-retrospective.md`

Runs the Keep-Problem-Try retrospective after the Sprint completes.

Key sections: Keep (what worked), Problem (what to improve), Try (what to attempt), action items, team satisfaction

---

## 6. Sprint Completion

**File**: `templates/sprint-completion.md`

Writes the Sprint completion report.

Key sections: completion summary, completed Tasks, carried-over Tasks, deliverables, commit history, quality metrics

---

## 7. Status icons

| Status | Icon | Description |
|--------|------|-------------|
| Pending | 📋 | Not started yet |
| In progress | 🔄 | Currently in progress |
| Done | ✅ | Complete |
| On hold | ⏸️ | Temporarily paused |
| Blocked | ⚠️ / 🚫 | Blocked by a dependency |
| Warning | ⚠️ | Needs attention |
