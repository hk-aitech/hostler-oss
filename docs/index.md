# Documentation Index

Documentation for **hostler-oss** is organised under numeric prefixes so the reading order is explicit. Each top-level directory has its own `index.md` that lists the documents inside.

| Prefix | Area | Purpose |
|---|---|---|
| `00-project/` | Project definition | PDD, roadmap, system overview, glossary |
| `01-requirements/` | Requirements | SRS, FRS, NFR, traceability |
| `02-architecture/` | Architecture | ADRs and architectural views |
| `03-design/` | Design | Detailed design (architecture / domain / features / API / UX / deployment) |
| `04-guides/` | Guides | Development, operations, troubleshooting, runbooks, playbooks |
| `05-operations/` | Operations | SLO, FMA, monitoring, data management |
| `06-reports/` | Reports | Analyses, audits, measurements, checklists, spikes |
| `07-knowledge/` | Knowledge base | Lessons, gotchas, domain insights |
| `08-references/` | External references | Third-party APIs, research, specifications |

## Conventions

- All documents are written in Markdown.
- Documents intended to be linked from elsewhere live under a stable filename.
- Architecture decisions follow the ADR pattern with sequential numbers (`ADR-001`, `ADR-002`, ...).
- Knowledge base cards live under `07-knowledge/<category>/` and are indexed in `07-knowledge/INDEX.md`.
